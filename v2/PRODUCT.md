# Product

## Register

brand

## Users

IT 채용담당자(1차 스크리닝)와 개발팀 리드/CTO(2차 기술 검증). 채용담당자는 신뢰성·안정감을 보고, 개발 리드는 기술 깊이와 실제 경험을 검증한다. 둘 다 짧은 시간 안에 판단을 내린다.

## Product Purpose

백엔드/인프라 엔지니어 JuneYoung Kim의 경력기술서 사이트. 포트폴리오(작업물 쇼케이스)가 아닌 경력 서술 중심. 성공 기준: 열람자가 "이 사람과 일하고 싶다"는 확신을 갖고 연락하는 것.

## Brand Personality

날카롭다, 무겁다, 독특하다. 과잉 없이 본질만 남긴 인상. 군더더기 없는 정밀함이 곧 엔지니어 본인의 작업 방식을 반영한다.

## Anti-references

- 화려한 포트폴리오 사이트: 파티클·3D·과도한 애니메이션 — 디자이너/프론트 느낌
- SaaS 랜딩페이지: 그라디언트 히어로, 기능 카드 3열, "지금 시작하기" CTA
- 일반 이력서 PDF 그대로: 흰 배경 텍스트 나열, 인터랙션 없음
- AI 티 나는 것: 크림 배경, 과도한 라운딩, 글로우 효과, 섹션마다 아이콘+제목+설명 카드

## Design Principles

1. **도구가 말하게 한다** — 기능(커맨드 팔레트, 스크롤 진행, 커스텀 커서)이 곧 엔지니어 역량의 증거
2. **과잉 없는 정밀함** — 한 요소가 하나의 역할만. 장식은 의도가 없으면 제거
3. **텍스트가 주인공** — 경력 내용이 디자인에 묻히지 않아야 한다
4. **엔지니어답게 직접적으로** — 모호한 표현 대신 수치·사실·결과

## Accessibility & Inclusion

WCAG AA 기준. 한국어 콘텐츠. 커스텀 커서는 `prefers-reduced-motion` 미디어쿼리 대응 필요.
